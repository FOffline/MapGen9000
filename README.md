MapGen9000 - simple FOnline map (.fomap) generator. Heavily inspired by legendary Desert Tiles Helper (dgen) by Realism.
Uploaded two versions, python and winforms. Whole source is here. Feel free to use, modify or whatever.<br/>
Ready to use stuff in Releases and here: https://www.mediafire.com/file/dxa577tnkijj6ty/MapGen9000.zip/file
To run .py file you need at least Python 3.8. To run .exe you may need install some NET runtime if you dont have already.
Short vid with use - https://www.youtube.com/watch?v=YDF31-Cypok
